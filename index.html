01 · Product

What we are building

The first version focuses on selected scheme and ITR checks. Every result must show the rule and source used.

A user enters their details, the system applies the matching rule version, and the result includes an explanation and source.

  1. Rule versions

    Earlier published rules remain available with their effective dates.

  2. Eligibility checks

    The system checks the user's details against written conditions.

  3. Source check

    A result is shown only when the selected source supports it.

  4. Document input

    Users can enter details manually when they do not want to upload a file.
